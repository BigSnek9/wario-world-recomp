# Input

- SISetSamplingRate(0) at 0x8004AA38 (../TIMING.md T002).
- Pad / input manager object `[0x801FDA90]`, held buttons at +0xE0, previous at
  +0xF0 (../TIMING.md T007/T009, probable).
- Menus use the analog stick for Yes/No (the D-pad does not select).
- Host mapping, rebinding and rumble: ../CONTROLS.md. While the in-game menu is
  open the game sees a neutral pad (../modding/IN_GAME_MENU.md).
